# Тихий день

Личный ежедневник на русском языке: месячный календарь, задачи, время, заметки, категории, поиск, перенос на любую дату и отметки выполнения. Адаптирован для телефона.

Статический сайт без сборки. Откройте через любой HTTP-сервер, например сервер из Node.js или Python. Все пути относительные и работают в подпапке GitHub Pages.

## Хранение

Без входа задачи хранятся в localStorage этого браузера. Кнопка «Сохранить копию задач» выгружает JSON. После входа через Supabase задачи сохраняются в базе. Для переноса локальных задач есть отдельная кнопка в настройках; автоматического смешивания данных нет. Облачные изменения требуют сети, ошибка сохранения показывается пользователю. При возврате во вкладку список обновляется.

## Supabase

1. Выполнить SQL из supabase/migrations/202611140001_planner.sql в отдельном проекте.
2. Указать URL и publishable (либо legacy anon) ключ в config.js или настройках интерфейса. Service role и secret key в браузере запрещены.
3. В Authentication настроить Site URL и Redirect URLs на адрес GitHub Pages.
4. Создать аккаунт через приложение, подтвердить email и войти.

Таблица защищена RLS: каждый пользователь читает и изменяет только свои задачи. В открытом репозитории нет пользовательских задач и секретных ключей.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save. Публикуется статический интерфейс; личные данные остаются в браузере или Supabase под RLS.
